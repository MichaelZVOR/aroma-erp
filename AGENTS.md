# Работа над Арома ERP

Обязательный стек: Next.js, Ant Design, Python API, SQLite. PostgreSQL не подключать.

- Менять только прямо запрошенный раздел и согласованный объём задачи.
- Не менять финансовые формулы и коэффициенты без явного согласования и примера расчёта.
- Не переименовывать товары и не подставлять альтернативные названия автоматически.
- Исходные названия, цены и реквизиты импорта брать из согласованного CSV.
- Не пересчитывать прошлые документы по текущим ценам справочника.
- Не загружать в Git рабочую базу, продажи, закупочные цены, фотографии, профили браузера и секреты.
- Не добавлять Gold Apple / Aroma-Butik в активный поиск без нового запроса владельца.
- Перед развёртыванием сделать резервную копию рабочей SQLite; базу тестовой не заменять.
- Проверять финансовые и складские операции на отдельной базе; интерфейс после установки — в браузере.
- Не считать создание кода завершённой установкой. В отчёте различать подготовку, проверку, установку и публикацию.
- Рабочая установленная Арома и папка исходников Git — разные экземпляры. Не копировать всю папку поверх рабочего каталога.

Для запуска и текущих ограничений см. README.md.
