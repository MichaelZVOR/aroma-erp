# Арома ERP

Локальное приложение для парфюмерного магазина: каталог товаров, калькулятор себестоимости, ручной журнал продаж, подготовка складского учёта и сравнение цен конкурентов.

## Технологии

- Next.js, React и Ant Design — интерфейс с экспортом статических страниц.
- Python 3.10+ — локальный API; стандартная библиотека, без сторонних Python-зависимостей.
- SQLite — данные на компьютере владельца.
- Зависимости интерфейса закреплены в `frontend/package-lock.json`.

## Запуск на Windows

Требуются установленный Python 3.10+, Node.js 22 LTS с npm и Git.

В PowerShell из папки репозитория:

```powershell
./scripts/build.ps1
./scripts/run.ps1
```

Открыть http://127.0.0.1:8788. Сервер доступен только на этом компьютере. Если порт занят работающей Аромой, сначала завершите её штатно или используйте другой порт.

Для отдельной тестовой копии можно задать:

```powershell
$env:AROMA_PORT = '8790'
$env:AROMA_DATA_DIR = 'C:/Aroma-Test-Data'
python server.py --no-browser
```

База создаётся при первом запуске. Репозиторий содержит пустой исходный каталог и пустые шаблоны калькулятора; рабочие товары и документы не публикуются.

Не используйте `npm run dev` как готовую замену Python-серверу: интерфейсу нужен его API. Основной способ запуска — статическая сборка и Python.

## Работа через GitHub

1. Создавать отдельную ветку для конкретной задачи: `git switch -c feature/task-name`.
2. Вносить только согласованные изменения, проверять расчёты и запуск.
3. Просматривать `git diff` и `git status` перед коммитом.
4. Создавать коммит и отправлять ветку, затем проверять изменения перед слиянием.
5. Перед установкой обновления в рабочую Арома делать согласованную резервную копию SQLite.

Рабочая установленная программа и этот репозиторий — разные папки. `git pull` сам по себе не обновляет установленный экземпляр. Не заменяйте рабочую папку целиком: база, фотографии и пользовательские шаблоны должны сохраняться при каждом развёртывании. Автоматическое развёртывание пока не настроено.

## Что остаётся только на компьютере

База SQLite, продажи, закупочные цены, резервные копии, CSV/Excel-файлы, фотографии, профили браузера, секреты и личные настройки. Они исключены из Git. `seed.json`, `calculator-seed.json` и `static/image-map.json` в репозитории пустые.

## Сравнение цен

Активны Allure Parfum, Odekolon, Randewoo и Духи.рф. Доступность внешних сайтов не гарантируется; отсутствие предложения и сетевая ошибка различаются. Gold Apple и Aroma-Butik исключены из активного поиска по указанию владельца. Оставшиеся файлы браузерного загрузчика не включают их обратно.

Некоторые исторические исходники запуска и неактивного браузерного загрузчика используют резервный путь к среде Codex. Основной запуск через Python не требует этой среды; перенос браузерного загрузчика на обычный Node.js — отдельная задача.

## Статус складского учёта

Каталог, фактические остатки и история документов — разные сущности. Импорт карточек не создаёт приход. Подготовка складов реализована; подключение продаж к списанию по магазинам и полный учёт перемещений требуют отдельных согласованных этапов.
